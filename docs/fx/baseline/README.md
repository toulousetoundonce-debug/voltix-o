# Baseline captures

Captured from the running site before visual changes at 1440×900, 1024×768 and 390×844.

The 27 PNG captures cover `#main`, `#control-center` (interactive lab), `#diagnostic` (radar), `#services`, `#comparison`, `#why-us`, `#portfolio`, `#team` and `#contact` (footer). `layout.csv` records the rectangles of every element with an `id` and every heading at each viewport. `Hn[n]` rows are the ordinal among headings of the same tag that do not have an `id`; `Hn#id` rows identify titled headings. Hidden and zero-size identified elements are recorded too. Re-capture with the same browser engine and viewport settings for a meaningful comparison.
